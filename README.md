# EduLearn

منصة تعليمية أونلاين: React (Vite + React Router) + Node.js API. الاتنين في مشروع واحد وبيشتغلوا بأمر واحد.

## التشغيل (Windows / PowerShell)

```powershell
npm run setup     # مرة واحدة: بينزل مكتبات المشروع والفرونت
npm run dev       # بيشغّل الباك اند (4000) والفرونت (5173) مع بعض
```

افتحي http://localhost:5173

> الباك اند من غير أي مكتبات (Node فقط). محتاجة Node 18 أو أحدث.

## حسابات تجريبية

| الدور | الإيميل | الباسورد |
|---|---|---|
| أدمن | admin@edulearn.com | Admin@12345 |

أول مرة بيتعمل `backend/data/db.json` ببيانات تجريبية (9 كورسات، 6 مدربين، كويزات، طلبات). لإعادة البيانات للأصل: `npm run reset-db` وبعدها شغّلي السيرفر.

## اللي بيشتغل فعلاً (من الباك اند)

تسجيل/دخول بتوكن، الكورسات (بحث + فلاتر + ترتيب)، المدربين والمتابعة، التقييمات، التسجيل في كورس مجاني، شراء كورسات من السلة، تقدم الدروس، الكويز (التصحيح في السيرفر)، الشهادات (بتتصدر تلقائي بعد 100% دروس + نجاح الكويز)، المفضلة، الملف الشخصي وتغيير الباسورد وصورة البروفايل، تذاكر الدعم ورسائل التواصل، ولوحة الأدمن (إحصائيات حقيقية، إدارة الكورسات والدروس والمدربين والمستخدمين والطلبات والتقييمات والدعم والإعدادات).

## الجديد

- **أنيميشن وحركة**: انتقال بين الصفحات، ظهور الأقسام مع السكرول، عدّاد أرقام، حركة للهيرو، تأثيرات hover/ضغط، وحركة للرسوم البيانية وأشرطة التقدم. بتتوقف تلقائياً لو الجهاز مظبوط على "تقليل الحركة".
- **إظهار/إخفاء الباسورد** (أيقونة العين) في تسجيل الدخول، إنشاء الحساب، الملف الشخصي، وفورم الطالب في الأدمن.
- **الأدمن بيعدّل كل حاجة**: الكورسات والدروس والصور، المدربين، الطلاب (إضافة، تعديل البيانات والباسورد والدور، إضافة/حذف كورسات)، الكويزات (أسئلة وإجابات ودرجة النجاح)، الشهادات (إلغاء)، الطلبات، التقييمات، الدعم، الإعدادات، و**Website Content**: نصوص وصورة الهيرو، شريط الأرقام، التصنيفات، الأسئلة الشائعة، About، بيانات التواصل، الفوتر وروابط السوشيال.

- **حركة متقدمة (من غير مكتبات إضافية)**: ظهور عنوان الهيرو كلمة بكلمة، طبقات بعمق مع حركة الماوس والسكرول، شريط تقدم السكرول، ظهور الصور بقناع وتكبير مع السكرول، ميل 3D لكروت الكورسات والمدربين على الديسكتوب، زر مغناطيسي لبحث الهيرو، ripple عند الضغط، سكيليتون أثناء التحميل، وسبينر على أزرار الإرسال. على الموبايل بدل الـ hover في ضغطة واضحة، وكله بيتوقف مع "تقليل الحركة".

## ملاحظات

- **الدفع تجريبي**: بيسجّل طلب ويفتح الكورس، ومفيش خصم فلوس حقيقي، وبيانات الكارت مش بتتبعت لأي مكان.
- الصور (Unsplash / randomuser) والفيديوهات التجريبية محتاجة إنترنت؛ لو مفيش بيظهر شكل بديل. تقدري تغيّري أي رابط من لوحة الأدمن.
- اللغة (EN / AR مع RTL) والدارك مود من الأزرار في الهيدر.
- للنشر الحقيقي: قاعدة بيانات حقيقية، HTTPS، `TOKEN_SECRET` في متغيرات البيئة، وبوابة دفع.
